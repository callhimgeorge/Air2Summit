# Kickstarter Graphic Copy - Open System

## Title
Open Where It Makes Sense

## Main copy
Air2Summit is being developed with an open design mindset.

We plan to release selected components such as tips, mounts, adapters, and accessories under an open hardware license.

Safety-critical parts, manufacturing details, and supplier-restricted components will remain controlled where needed.

The goal:
As open as possible, without compromising quality, safety, or delivery.
