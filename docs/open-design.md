# Open Design Approach

Air2Summit uses an open design mindset.

Selected parts will be released where practical, with emphasis on components that are useful to others without exposing safety-critical or manufacturing-restricted details.

Accessories, mounts, tips, and adapters are good candidates for open release.

Structural joints, locking mechanisms, clamp details, and manufacturing-specific details are controlled for now.

The future aim is to expand the release set over time through more CAD releases, community add-ons, and an open accessory ecosystem.

Selected open components are intended to use CERN-OHL-W v2 licensing. See LICENSE.txt for project licensing details.

"As open as possible, without compromising quality, safety, or delivery."
